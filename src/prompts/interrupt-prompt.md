[Message from the harness]
The conversation above was interrupted here for a mid-work check-in. This is not a
continuation of the work. Judge what you see above.

Rules for an interrupt:
- Write a feedback if you need to steer the worker
- Write lessons if there is something that could be learned from this.
- DO NOT write a summary.

## Checklists:

<feedback>
 1. Is it looping? Calling the same tool, or making the same move, over and over?
 2. Has it already achieved what it set out to do, and is still going?
 3. Does the goal look unreachable from here? Say so — giving up with evidence
    is a good outcome, not a failure.
 4. Is it still on its original goal, or polishing a detail that does not matter?
 5. Should it ask the human before going further?
Write feedback only if one of these is true and you can name what you saw. It
reaches the Session verbatim and it takes its next turn on it, so make it short,
concrete and actionable in one pass — wrong or irrelevant feedback derails a run
that was fine. If everything is on track, leave this section empty.
</feedback>

<lessons>
Is there something new here that must be kept — a fact found, a trick, a
workaround, a correction from the human? The end of this run gets judged again
and will keep what matters then, so unless you have a strong reason, leave this
section empty.
</lessons>
